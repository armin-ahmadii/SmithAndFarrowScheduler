# Smith and Farrow Scheduler

## Problem
Smith and Farrow Scheduling feels very old school, having to inquire the concierge for everything.
The portal to view schedules is outdated, not sure how easy it is for concierges to add.

## Solution
We are building a Web App that unifies all of this, strictly for use by Smith and Farrow. Non-profit.

## How It Works (High Level)
- User sees a calendar with all events around the building
- The user can create a request for a booking, where they must agree to the rules.
- Request is sent to Admin for approval. If approved, a ticket is opened so parties can communicate and deal with the deposit and further information.
- The ticket system will be stored on a secure database and/or can be saved as a PDF invoice for bookkeeping.
